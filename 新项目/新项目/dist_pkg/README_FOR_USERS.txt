打开网页工具 - 分发包

包含：
- 打开网页工具.exe (单文件 Windows 可执行程序)

使用说明：
1. 下载并解压本 ZIP 到任意文件夹。
2. 右键 exe -> 属性 -> 如果看到“解除阻止（Unblock）”，请勾选并点击确定。
3. 双击运行 `打开网页工具.exe`。如有 SmartScreen 警告，可选择“更多信息” -> 仍要运行。（如公司策略禁止，请联系管理员）
4. 配置文件（网址列表）保存在：%APPDATA%\打开网页工具\urls.json（每个用户独立）。

校验文件：`SHA256.txt` 中包含 exe 的 SHA256 值，用于验证文件完整性。

验证 SHA256（Windows）:
  certutil -hashfile "打开网页工具.exe" SHA256
